# 云函数部署与配置

本项目小程序端只调用一个云函数：**`api`**（`cloudfunctions/api`）。

- `api`：登录建档、学籍登记、作业、活动、志愿活动、交流、课程设置等全部写操作；所有权限校验都在这里完成。
- `quickstartFunctions`：微信官方模板示例，本项目未使用，可以忽略或删除。

---

## 一、开通云开发，拿到环境 ID

1. 用微信开发者工具打开本项目。
2. 点击工具栏「云开发」，按提示开通/进入控制台。
3. 进入「设置 → 环境设置」，复制**环境 ID**（形如 `huiyingzhai-1a2b3c4d`）。

## 二、填写环境 ID

打开 `miniprogram/app.js`，填写：

```js
globalData: {
  env: "你的环境ID",
  ...
}
```

> 只有一个云开发环境时可以留空，SDK 会使用默认环境。

## 三、上传部署云函数

在微信开发者工具的文件树中：

1. 右键 `cloudfunctions/api` 目录。
2. 选择 **「上传并部署：云端安装依赖」**。
3. 等待上传完成（首次会安装 `wx-server-sdk`，约 1～2 分钟）。
4. 在「云开发 → 云函数」中确认 `api` 已出现，并且版本是刚上传的。

> 修改云函数代码后，都需要重新执行这一步才会生效。

## 四、数据库集合与权限

云函数首次运行时会**自动创建**以下集合：

```
users, homeworks, sign_tasks, sign_records, activities,
posts, post_replies, subject_settings, subject_tasks
```

如果自动创建失败，也可以在「云开发 → 数据库」中手动创建同名集合。

### 权限设置（很重要）

小程序端会直接读取数据库来展示列表和全班名单，所以每个集合的权限都需要设置为：

> **所有用户可读，仅创建者可读写**

（控制台：数据库 → 选中集合 → 权限设置）

说明：

- 读：列表页、交流页、课代表选择页都需要读取其他用户的数据，必须是「所有用户可读」。
- 写：小程序端的所有写操作都走云函数，**云函数不受数据库权限限制**，所以客户端不需要写权限。
- `users` 集合也一样：客户端只读，登记由云函数写入。

## 五、云存储（作业附件）

作业附件通过 `wx.cloud.uploadFile` 上传到云存储。默认权限即可；如果上传失败，到「云开发 → 存储 → 权限设置」确认已登录用户可以上传。

## 六、部署后验证

### 1. 云函数自检

在微信开发者工具的 Console 中执行：

```js
wx.cloud.callFunction({ name: "api", data: { action: "ping" } }).then(console.log)
```

正常应返回：

```js
{ result: { ok: true, pong: true, openid: "...", time: ... } }
```

### 2. 小程序端验证

1. 重新编译，进入「我的」页：首次打开应提示未登记并自动弹出登记窗口。
2. 用管理员学号 `2026014720`（於文质）或 `2026014704`（张昊霖）登记，身份应显示「管理员」。
3. 云开发控制台 → 数据库 → `users`，应能看到当前微信账号的记录（含 `_openid`）。
4. 用班委账号发布一条作业，其他账号打开作业页应能看到。

## 七、常见错误排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `FunctionName parameter could not be found` / `-501000` | 云函数没上传，或环境选错 | 重新右键 `api` 上传部署；确认开发者工具当前环境 |
| `Environment not found` / `env check invalid` | `app.js` 的 `env` 填错 | 与环境设置里的环境 ID 逐字核对；单环境可留空 |
| `database collection not exists` | 集合未创建 | 云函数首次调用会自动创建；重新编译再试，或在控制台手动创建 |
| 列表一直空白 / 提示加载失败 | 集合权限不是「所有用户可读」 | 按第四节重新设置权限 |
| 登记时提示「请先完成入斋登记」反复出现 | `users` 里没有当前账号记录 | 看云函数日志；确认 `api` 是最新版本 |
| 登记提示「该学号已被注册」 | 同一学号被其他微信账号登记 | 在控制台删除冲突的 `users` 记录，或联系管理员 |
| 职位不对 | 学号不在名单字典里 | 修改 `miniprogram/utils/roster.js` 和 `cloudfunctions/api/roster.js`，两份保持一致后重新部署 |

查看云函数日志：云开发控制台 → 云函数 → `api` → 日志。

## 八、名单与权限规则

- 学号 → 职务：`miniprogram/utils/roster.js` 与 `cloudfunctions/api/roster.js`，**两份必须保持一致**。
- 管理员学号：`ADMIN_IDS`（当前为 `2026014704`、`2026014720`）。
- 职务与角色由云函数根据名单字典判定，客户端传入的职位不会被信任。
- 课代表由管理员在「学科板块 → 课程设置」中指定，登记时不可自选。
